# Painel de Divulgação — Antes do Primeiro Gole

MVP da **Etapa 1**: aplicativo web instalável (PWA) para organizar a divulgação sem acessar ou controlar a conta do Instagram.

## Funções incluídas

- visão geral do projeto;
- calendário editorial;
- criador assistido de posts, carrosséis, Reels, Stories e mensagens institucionais;
- biblioteca de frases conferidas do livro e da cartilha;
- mapa inicial de prospecção;
- fila de aprovação humana;
- registro manual de métricas;
- links oficiais configuráveis;
- backup e restauração em JSON;
- funcionamento offline após o primeiro carregamento.

## O que o MVP não faz

- não solicita senha do Instagram;
- não segue, curte, comenta ou envia DMs;
- não raspa perfis ou seguidores;
- não publica automaticamente;
- não envia mensagens em massa;
- não usa API da Meta nesta etapa.

## Instalação no celular

Depois de publicar no GitHub Pages, abra o endereço no Chrome e use **Adicionar à tela inicial** ou **Instalar app**.

## Segurança

Os dados ficam no `localStorage` do navegador. Exporte backups periodicamente. O painel é um assistente editorial: publicação e contato continuam sob decisão humana.
